# Myraha Status Helper

Подієве Chrome-розширення на TypeScript і Manifest V3. Воно показує Facebook cookie наживо, зберігає введений користувачем токен локально та надсилає серверу лише статус зміни.

## Запуск

1. Встановіть Node.js 20+.
2. Виконайте `npm install`.
3. Вкажіть URL у `.env` (секрети краще не вбудовувати).
4. Виконайте `npm run build`.
5. Відкрийте `chrome://extensions`, увімкніть режим розробника, натисніть **Load unpacked** і виберіть папку `dist`.

Для розробки: `npm run dev`, після перебудови натискайте Reload на сторінці розширень.

## Як це працює

- Service worker прокидається лише на встановлення, запуск Chrome, подію зміни cookie, ручну перевірку або погодинний alarm.
- Події перезапису cookie об'єднуються затримкою 30 секунд.
- Сирі cookie читаються лише для локального показу й обчислення SHA-256-відбитка; у `chrome.storage` зберігається тільки відбиток.
- Локальні логи обрізаються до останніх 200 записів і не містять cookie або токена.
- Після вимкнення перевірки та запити ігноруються.

Контракт сервера: [docs/server-api.md](docs/server-api.md).

Чернетка політики конфіденційності: [PRIVACY.md](PRIVACY.md).

## Дозволи

- `cookies` + `https://*.facebook.com/*`: читання та відстеження Facebook cookie.
- `storage`: налаштування, відбитки та логи.
- `alarms`: погодинні та повторні перевірки.
- адреса API запитується як optional host permission у момент збереження налаштувань.

Перед публікацією потрібні точна privacy policy, disclosure у Chrome Web Store та явна згода користувача на роботу з authentication data.
